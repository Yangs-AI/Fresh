# Python Project Preliminaries

This directory contains a collection of tutorial-style “recipes” designed to help users complete essential preparation steps for development.

## Contents

- Tutorial for WSL, VS Code, and Python setup (PDF):  
  [`Python Project Preliminaries (ZH Version).pdf`](WSL-VSCODE-PYTHON-GUIDE.pdf)

## Purpose

The aim of **tutorial_recipes** is to provide clear and practical guidance that supports quick onboarding.  

This PDF presents a complete from-scratch workflow for beginners. It introduces the configuration of WSL, Ubuntu, VS Code, and the required Python environment, so users can begin running Python projects in a clean and reliable setup.
