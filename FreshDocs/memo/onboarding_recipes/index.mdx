The **Onboarding Guide** offers a collection of carefully designed setup instructions and configuration scripts aimed at helping new researchers quickly build a complete and reliable research environment from scratch.

---

### Overview ⚙️

Each guide in this section is designed to:

- Walk **new lab members** through essential setup steps - from installing core tools to configuring development environments across systems.
- Provide **ready-to-use scripts and configuration templates** that standardize and simplify the initialization of research projects.
- Ensure a **consistent, reproducible, and collaboration-ready foundation** for everyday scientific tasks such as data analysis, writing, and version control.

:::tip
Some examples (more coming soon):

- **Zotero Setup** - Configure a powerful literature management system with synchronization and group sharing for efficient citation use.
- **V2Ray Setup** - Establish secure and flexible network access for international research resources.
- **RC Environment** - Build a fast, elegant, and extensible Linux command-line workspace for daily research tasks.
:::

---

### Purpose 🧭

Scientific research should focus on **exploration and creation**, not on tedious environment setup.
The **Onboarding Guide** offers **lab-tested, broadly applicable configuration practices** that enable researchers to rapidly establish an efficient and reproducible workflow, while eliminating redundant setup barriers.

Each recipe is **modular**, **transparent**, and **customizable** - designed not only to help you configure tools, but also to **cultivate the craftsmanship and collaborative discipline of modern scientific work**.
